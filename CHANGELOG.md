# Changelog

All notable changes to StatData Converter are documented here.

## 0.10.0

- Added Linux x64, Windows x64, macOS ARM64, and macOS Intel package builds.
- Added installer-level smoke tests that extract or mount finished packages.
- Added packaged CSV-to-XLSX conversion and fidelity-report validation.
- Added local-only privacy and certification-contract checks to package CI.
- Added signed-release preparation, artifact manifests, checksums, and build
  provenance.
- Expanded native and optional bridge coverage for SAS, JMP, Minitab,
  Statistica, EViews, R, JSON-stat, SPSS, Stata, Excel, and CSV.
- Added direction-specific vendor-certification evidence controls.
